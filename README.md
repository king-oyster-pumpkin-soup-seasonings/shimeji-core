#  Portfolio

My personal portfolio built with Next.js and Tailwind CSS.

## Stack

- Next.js 16
- TypeScript
- Tailwind CSS v4
- Jersey 25 + New Tegomin (Google Fonts)

## Running locally

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

Deployed on Vercel at https://shimeji-core.vercel.app/.
